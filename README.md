# MyBlog — Basic Blogging Website (SEIT2270 Web Application Development)

## Folders
- frontend/  : home.html, about.html, blog1.html, admin.html, css/style.css, js/app.js, images/avatar.jpg
- backend/   : server.js (Node.js, no extra packages), package.json
- remaining/ : this README

## How to run
1. cd backend
2. node server.js
3. Open http://localhost:3000/home.html  (write posts at /admin.html)
Publishing a post creates a new blogN.html in frontend/ and adds its card to home.html.

## Syllabus topics used
- Unit 1 HTML5: headings, paragraphs, lists, links, images, forms, semantic tags
- Unit 2 CSS3: variables, box model, Flexbox, Grid, media queries, dark mode
- Unit 3 JavaScript: DOM, events, form validation, comments
- Unit 4 Advanced JS: let/const, arrow functions, template literals, destructuring, fetch + async/await, localStorage
- Unit 6 Back-End: Node.js server handling POST /api/publish and serving files
